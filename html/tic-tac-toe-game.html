Tic-Tac-Toe

Game

2024

Project Overview

This is a desktop-based Tic Tac Toe game developed using JavaFX for the graphical user interface, Java as the core programming language, and MySQL for data persistence. The game offers a classic two-player experience with additional functionality for storing and retrieving game data from a database.

Key Features

  • Interactive GUI built with JavaFX, featuring a clean 3x3 grid layout.
  • Score tracking and ability to store game results in a MySQL database.
  • Input validation and error handling to ensure smooth gameplay
  • Two-player gameplay with automatic win/draw detection and turn switching.

Why Auto Rent Pro?

  • Practiced building interactive desktop applications with real-time feedback.
  • Gained experience with SQL queries and database integration using JDBC.
  • Enhanced knowledge of object-oriented programming and code organization in Java.
