Assignment 01

Portfolio

2025

Assignment Overview

Create a personal portfolio website that showcases your background, skills, projects, and goals. This project will help you demonstrate your ability to design, plan, and implement a real-world web application.

Key Features

  • Contains the project goals, outlining the purpose and desired outcomes of the portfolio.
  • Includes wireframes to visually represent the structure and layout of the portfolio.
  • Presents mockups to show the intended design and aesthetic of the final product.
  • Hosts the source code for the portfolio.
  • Demonstrates your ability to translate the design into a functional website using appropriate technologies (e.g., HTML, CSS, JavaScript, React, etc.).

Skills Demonstrated

  • Project planning and goal-setting
  • UI/UX design with wireframes and mockups
  • Web development and responsive design
